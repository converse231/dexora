# Friend Invite rewards: art prompts

Pokémon you can only get by inviting friends who get going. The four sprites are drawn and in the game. Only the title badge is still to draw.

**How to use**
- Start a new Gemini chat for each prompt, and attach its reference sprite if it has one.
- Save the badge as `art/titles/event-friends.png`, then run `npm run ranks`. Until then the title shows as words.
- A redrawn Pokémon goes at the path beside its name, then run `npm run eventart`.

**The ladder**
- 1 friend: Pikachu, for you and your friend
- 3 friends: Charizard
- 5 friends: Mewtwo
- 10 friends: Arceus, plus the title and medal

---

```

Use the attached Pikachu sprite as the exact base: the same pose, the same facing, the same body, proportions and colours - redraw it pixel for pixel and only add the costume over it.
