# Origin retro prompts

Origin after Johto, redrawn for Dexora one batch at a time. Each prompt
makes ONE sprite. Save each image at the path above its prompt (PNG or
JPG, any size - square is best), then run `npm run retro`: it keys out
the white, shrinks the drawing onto the species' own canvas, holds it to
six colours and lists it in `src/data/retro.js`, so that species can be
Origin again. A drawing that needs a redo: replace the file and run it again.

Batch 1: every starter from Hoenn on, then ten favourites.
