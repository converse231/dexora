# Shichi-Go-San event: art prompts

The event runs November 10 to 16, 2026: Japan's 7-5-3, when children aged three, five and seven are dressed up and taken to a shrine, and come home with *chitose-ame*, thousand-year candy.

**How to use**
- Start a new Gemini chat for every Pokémon.
- Save each result as `art/events/shichigosan/<number>.jpg`, then run `npm run eventart`.
- Save the title badge as `art/titles/event-shichigosan.png`, then run `npm run ranks`.

**The look** (2026-10-27, asked for, from the Haunting sprites: Kitsune Vulpix, Swamp Tangrowth, Fortune Teller Abra, Phantom Thief Sableye, Pirate Wingull). The Pokémon keeps its own body, colours and pose. It wears two or three bold costume pieces that read at a glance, plus ONE signature touch that makes it feel magical (floating flames, petals, sparkles, a glowing prop). If Gemini redesigns the body, reply in the same chat: "keep the Pokémon's normal body and colours, only add the costume".

**The three lines are the three ages.** The first stage is three (a small padded vest), the second five (a striped hakama skirt and haori jacket), the final seven (a long-sleeved kimono top and a wide obi sash).
