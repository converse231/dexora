# Grateful Harvest event: art prompts

Thanksgiving week (Nov 22-28): a harvest festival, with Shaymin - the Gratitude Pokémon - as the hunt.

**How to use**
- Start a new Gemini chat for every Pokémon, and attach its reference sprite (`art/events/ref/<id>-<name>-front.png`).
- Save each result as `art/events/harvest/<number>.jpg`, then run `npm run eventart`.
- Save the title badge as `art/titles/event-harvest.png`, then run `npm run ranks`.

**The look.** The Pokémon keeps its own body, colours and pose (the game's sprite). It wears two or three bold harvest pieces that read at a glance - straw hats, baskets, gingham, wheat - plus ONE magical touch (golden leaves, glowing olive oil, warm steam, pollen). If Gemini redesigns the body, reply in the same chat: "keep the Pokémon's normal body and colours, only add the costume".

**31 costumes.** Lines evolve in costume: Skwovet → Greedent, Smoliv → Dolliv → Arboliva, Cherubi → Cherrim, Applin → Appletun or Flapple, Chespin → Quilladin → Chesnaught, Fidough → Dachsbun, Sunkern → Sunflora, Wooloo → Dubwool, Mudbray → Mudsdale, Combee → Vespiquen. One of a kind (they never evolve): Miltank and the feast table - Feast-Day Snorlax, Stuffed-Bulb Bulbasaur, Roast-Master Charmander and Cranberry-Bog Squirtle - and the farm: Leek-Harvest Farfetch'd and Potato-Dig Diggersby. And Turkey-Tail Unfezant is met in Pidove's place too (no Pidove or Tranquill look).
